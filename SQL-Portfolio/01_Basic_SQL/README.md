# Basic SQL

This section covers the fundamental SQL concepts that form the foundation of database querying and data retrieval.

These commands are widely used by Business Analysts to retrieve, filter, sort, and summarize business data for reporting and decision-making.

---

# 📚 Topics Covered

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING

---

# 💼 Business Relevance

Business Analysts use these SQL concepts to:

- Retrieve business data from databases
- Filter records based on business requirements
- Sort information for reporting
- Group data for analysis
- Generate summary reports for stakeholders

---

# 🛠️ Tools Used

- MySQL
- SQL
- GitHub

---

# 🎯 Learning Outcome

After completing this section, you will be able to write basic SQL queries to retrieve and analyze data, laying the foundation for advanced SQL concepts used in Business Analysis.
